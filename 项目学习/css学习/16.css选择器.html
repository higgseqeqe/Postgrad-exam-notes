css选择器式css规则的第一部分。他是选择html元素的方式

css选择器：选择标签；
css属性：修改样式
分类：
基础选择器
关系选择器
分组选择器
伪类和伪元素

基础选择器

类型选择器 ：p
类型选择器选择某个类型的元素，也称为标签选择器 遵循就近原则

类选择器 ：.box
类 一般直接 .da 直接取名就是
在 html 里面 以class来命名
类选择器，实现差异化选择
类选择器的权重优先级高于类型选择器

id选择器：#box

选择html 中具有特定id属性的唯一元素

与类选择器非常相似

类和id选择器的区别

类选择以.开头，后跟类名（如.bav）

选择class属性的一个或多个元素

特点：可以使用多次

类似:身份证的名字，可以使用多次

id选择器

以#开头，后跟id名

在同一页面中,id值必须唯一

类似身份证的编号，唯一，只能使用一次

通配符选择器：*

通配符选择器可以选择HTML中所有的标签，进行样式修改。

特殊情况下通过通配符清除所有元素的默认边距和填充，统一不同浏览器的默认样式。
