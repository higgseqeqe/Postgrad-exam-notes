路径分类

路径用于指定图片、样式表或网页等文件的位置。常见路径分为相对路径和绝对路径。

二、相对路径

相对路径以当前文件所在的文件夹为起点。./ 表示当前目录，../ 表示上一级目录。

  • 同一级：6图像标签及格式.html。
  • 下一级：img/image-3.png，访问项目自己的图片。
  • 上一级：../1.计算机网络体系结构.md，定位根目录的笔记文件。
<img src="img/image-3.png" alt="项目学习示例图片">

根目录的 Markdown 笔记引用自己的图片时，写成：

![图片说明](笔记图片/image-3.png)

三、绝对路径

绝对路径提供完整位置，例如本机文件地址 file:///C:/Users/chengling/Desktop/考研学习笔记/项目学习/img/image-3.png，或完整网络地址 https://example.com/images/photo.jpg。

本机绝对路径依赖电脑上的具体位置，移动文件夹或换电脑后可能失效。本项目内部使用相对路径，整体移动文件夹时更方便。

四、检查路径

  • 路径使用正斜杠 /，文件名和扩展名应与实际文件一致。
  • 笔记图片放入“笔记图片”，项目图片放入“项目学习/img”，分别管理。
  • 即使两个文件夹中存在同名图片，它们也是不同文件，引用时要写对目录。
  • 移动图片后，需要同时更新 Markdown 的图片链接或 HTML 的 src 属性。
